Website institucional desenvolvido como projeto de prática em Desenvolvimento Front-end, com foco em animações, transições e interações visuais.

O projeto foi criado para explorar diferentes técnicas de HTML, CSS e JavaScript, buscando desenvolver uma interface mais dinâmica e uma experiência de navegação fluida.

Tecnologias utilizadas
HTML5
CSS3
JavaScript
Animações e transições CSS
Manipulação do DOM
Design responsivo
Sobre o projeto

O EKbára foi desenvolvido principalmente como um projeto de aperfeiçoamento em Front-end. O objetivo foi experimentar diferentes possibilidades de animação e interação, indo além de uma página estática.

Durante o desenvolvimento, foram explorados conceitos como:

Transições e animações de elementos
Interações utilizando JavaScript
Manipulação de elementos do DOM
Efeitos durante a navegação
Responsividade
Organização de componentes visuais
Experiência e fluidez da interface
Objetivo

A principal finalidade do projeto foi praticar e aprimorar habilidades de desenvolvimento web, especialmente na criação de interfaces interativas e visualmente dinâmicas.

O projeto também serviu como laboratório para testar novas técnicas de animação e compreender melhor como HTML, CSS e JavaScript podem trabalhar juntos para criar experiências mais interessantes na web.
